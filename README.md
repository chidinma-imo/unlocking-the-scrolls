# Unlocking the Scrolls

A cinematic, manuscript-inspired landing page for **Unlocking the Scrolls**.

## Run locally

Open `index.html` in a browser, or use a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

Upload the files in this folder to a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The site uses Three.js and Google Fonts from CDNs, so the published site needs an internet connection for those assets.
